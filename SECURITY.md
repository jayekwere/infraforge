# Security policy

This is an offline prototype, not production-ready. Do not expose its loopback API publicly. Use synthetic requests and distinct random bearer tokens. Server identity configuration is trusted administrator input. Report vulnerabilities privately through GitHub private vulnerability reporting if enabled; otherwise contact the maintainer before publishing exploit details. Do not include secrets in reports.

Supported release: 0.1.x. Security-sensitive changes require negative tests. Cloud execution must remain disabled until durable approval, state protection and independent destructive-operation approval exist.
